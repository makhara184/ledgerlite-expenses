# LedgerLite — Expense & Budget Dashboard

A clean, offline-ready expense tracker and monthly budget monitor with automatic category breakdowns and CSV export.

## Features
- **Live Budget Tracking**: Instant alert styling when spending exceeds your monthly target.
- **Category Breakdown Bars**: Visualizes spending share by category automatically.
- **CSV Export**: Download all transactions for spreadsheet analysis.

## Quick Start
Open `index.html` in your browser.
